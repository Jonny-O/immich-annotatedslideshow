This is a simple routine that can display an Immich photo album as a slideshow. Simply give it an Immich API token to log in with and it'll show you a grid of your available photo albums. Set your desired slide display duration time and whether you want it to loop or not, and pick an album to display. Photo comments are displayed at the bottom of the image. There are manual controls at the bottom of the window during the presentation should you need them.

The program defaults to using port 3000, but you can change this in the docker-compose file.
